Infrastructure Security Parameters
IMDSv2 Enforced Execution

Amazon EC2 instance metadata service mandates session tokens (hop limit = 2), mitigating SSRF (Server-Side Request Forgery) credential exfiltration vectors.

Data-at-Rest & Data-in-Transit Encryption

Amazon S3 applies SSE-S3 AES-256 encryption at rest, paired with an explicit bucket policy that rejects any insecure (non-HTTPS) transmission.

Zero Persistent Access Keys

No AWS access keys are embedded or configured in environment files. All AWS service calls utilize scoped IAM roles and instance profiles.

Ephemeral Presigned Access

S3 public read access is 100% disabled. Ingested files are accessible exclusively through cryptographic HMAC-signed Presigned URLs valid for 300 seconds.
